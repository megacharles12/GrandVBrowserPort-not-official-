# GrandVBrowserPort-not-official-
This is the non-official clone of the Grand V port, originally produced by someone else (RIP).


NOTE: THIS IS **NOT** AN OFFICIAL PORT. ALL GAME ASSETS ARE SOMEWHERE ELSE. MAC SUPPORT AND LINUX SUPPORT WEREN'T ARCHIVED. PLEASE SEND THEM TO ME OR USE THE ISSUE FORUM TO SEND THEM.*

<img width="987" height="937" alt="Screenshot 2026-10-18 102037" src="https://github.com/user-attachments/assets/ef72be3e-0d18-42fe-9423-65b9db27c1ca" />

In short: This tool allows you play this game via the browser, with webassembly and webgpu. The tool initiates a localhost session that allows you to play in either story mode or in sandbox mode. Fully customizable settings allow you to play on lower hardware specs. Mods are allowed as well. Mobile support is purely experimental. **I HAVE NO CODING EXPERIENCE, SO DON'T EXPECT UPDATES.**
